# About

This project was developed as part of the final assignment for our Health Information Standards and Terminologies course. Our main objective was to create a complete ETL (Extract, Transform, Load) pipeline that demonstrates how healthcare systems can interoperate using widely adopted standards such as FHIR, SNOMED CT, and HL7.

We extracted patient data from OpenEMR, transformed the data using SNOMED CT hierarchies to ensure semantic consistency, and posted the resulting structured resources to a Primary Care FHIR server. This process reflects real-world workflows in healthcare data exchange and highlights the importance of standardized formats and terminologies for seamless interoperability between clinical systems.
